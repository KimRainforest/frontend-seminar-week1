# 프론트엔드 세미나 1주차 과제

## 목표

리액트를 이용해 메뉴에서 상품을 선택하고 장바구니의 수량과 총 금액을 관리하는 간단한 키오스크를 구현합니다.


## 기본 요구사항

### (1) 화면 구성

- 화면은 '메뉴 영역'과 '장바구니 영역'으로 이루어집니다.
- [피그마 와이어프레임](https://www.figma.com/design/0nJGOSt8bG0Qk8jslZD7TF/FE-%EC%84%B8%EB%AF%B8%EB%82%98_%EA%B3%BC%EC%A0%9C-%EB%B3%B4%EC%A1%B0%EC%9E%90%EB%A3%8C?node-id=0-1)를 참고하되, 이 디자인대로 구현할 필요는 없습니다.

### (2) 메뉴 영역
- 3개 이상의 상품이 존재해야 합니다.
- 각 상품에는 사진과 이름, 가격이 표시되어야 합니다.
- 각 상품 카드를 클릭하면 해당 상품을 장바구니에 담습니다. 이미 장바구니에 있는 상품이었다면 해당 상품의 수량이 1 증가합니다.

### (3) 장바구니 영역

- 장바구니의 각 상품에는 이름, 가격, 현재 수량, `+` 버튼, `-` 버튼이 표시되어야 합니다.
- `+` 버튼과 `-` 버튼을 이용하여 해당 상품의 수량을 변경할 수 있어야 합니다.
  - `+` → 수량 1 증가
  - `-` → 수량 1 감소
  - 수량이 `0`이 된 상품은 장바구니에서 제거
- 아직 담은 상품이 하나도 없다면 상품 목록 대신 장바구니가 비어 있음을 나타내는 UI를 표시합니다.
- 현재 장바구니를 바탕으로 담긴 상품의 총 수량과 금액을 표시합니다.


## 추가 구현사항

다음 중 하나를 선택하여 구현합니다.

### A. 주문하기 버튼 구현

지금 주문하기 버튼에는 기능이 없는 상태입니다. 다음 동작을 구현하세요.

- 장바구니가 비어 있으면 주문하기 버튼을 비활성화한다.
- 상품이 하나 이상 장바구니에 담기면 주문하기 버튼을 활성화한다.
- 주문하기 버튼을 클릭하면 주문이 완료되었음을 알리는 `alert()`를 띄운 뒤, 장바구니를 초기화합니다.

### B. 카테고리 필터 구현

각 상품에 카테고리를 지정하고, 사용자가 카테고리를 선택할 수 있는 필터를 구현하세요. 아래 조건을 만족해야 합니다.

- 최소 2개 이상의 카테고리를 사용할 것
- 특정 카테고리를 선택하면 해당 카테고리에 속한 상품만 메뉴 영역에 표시할 것
- 모든 상품을 다시 볼 수 있는 전체 옵션을 포함할 것


## 주요 명령어

- `yarn dev` — 개발 서버를 실행합니다.
- `yarn check-all` — 타입, 포맷, 미사용 코드 검사를 실행합니다.
- `yarn build` — 프로덕션 빌드를 생성합니다.
